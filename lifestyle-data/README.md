# 趣味・関わり方・生活の質の参照データ

家猫ver2.19で使用する公式公開集計。調査個票は使用しません。

- [利用画面と出典](https://tokmatsuno.github.io/ieneko2/lifestyle-data/?v=2.19)
- [参照35項目CSV](ieneko-lifestyle-reference.csv)
- [出典・利用条件・元ファイルURL](sources.json)
- [項目説明](data-dictionary.json)
- [抽出値と元ファイルのSHA-256](data.json)

2021年社会生活基本調査の趣味12項目・ボランティア3項目、社会意識に関する世論調査（2025年10月調査）の現在5項目・望ましい付き合い6項目、満足度・生活の質に関する調査2026の要因6項目・平均3項目、計35項目です。

`raw/`は公式配布ファイルの取得時のバイト列を保持します。社会意識調査の2件はブラウザーの公式ダウンロードリンクから取得。他の4件は出典URLから取得しました。取得日2026-11-02。社会意識調査は確報（2026-03-04掲載）を使用し、速報とは混ぜていません。

`python3 scripts/build-lifestyle-data.py`で、元Excel・CSVからdata.json、ブラウザー用lifestyle-data.js、参照CSVを再生成。`--check`は差分がないか照合します。標準ライブラリだけを使い、外部通信しません。CSVのラベルと値はセル位置を保存し、複数回答を100%に調整しません。社会生活基本調査の数値は10歳以上人口の推計割合で、人口112,462千人を調査標本数とは扱いません。

趣味を好きかどうかと、実施したことがあるかは別です。全国の分布を町内会へ割り当てず、本人が選んだ条件の参考に表示します。満足度調査はインターネット調査で、項目への回答が参加案の効果を示すものではありません。

3つの条件を使った遊び・おやつ・環境の案はTeam 1の設計であり、効果は未検証です。条件選択は端末画面内のフィルターで、外部へ送信しません。既存5問の保存・公開CSVの項目を増やしていません。5つの仮想のまちの90件へも趣味等を後付けしていません。

データの再利用時はsources.jsonの調査別帰属表示・原典URL・利用条件を引き継ぎ、加工したことを明記してください。
