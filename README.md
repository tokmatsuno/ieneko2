# 家猫クエスト II

地域への小さな関わり方を、5つの問いと100匹の家猫から探すシビックRPGです。

公開アプリ: https://tokmatsuno.github.io/ieneko2/

## 現在のバージョン: ver2.02

フッターに「2026年度東京大学シビックテックデザイン学講座Team 1」と `ver2.02` を表示します。版番号は `version.js`、更新履歴は [CHANGELOG.md](CHANGELOG.md) に記録。以後のコミット件名も `verX.XX: 更新内容` とします。

元絵を参照した9種類のポーズを追加し、合計14種類にしました。毛を逆立てる猫、酔拳風、はいオッパッピー風、電動キックボード、昼寝、スポーツカー、ギター、読み聞かせ、庭づくりです。画像は `dist/cat-*.png`、内蔵画像編集機能へ渡した制作条件は `dist/pose-prompts-ver2.02.json` に保存しています。

猫の選定用の元座標は維持。中心 (5,5) を基準とする4象限に、まちでみんなと・まちで自分らしく・おうちでだれかと・おうちで気ままに、という創作の場面を割り当てます。象限の候補から5問の回答経路でポーズを決めます。根拠データからポーズや人物の性質を推定したという意味ではありません。

結果カードの「相棒の、ほかの一日を見る」から、同じ毛色・模様・瞳のまま別のポーズを選べます。この選択は記念写真だけに反映し、設計座標や選定された猫は変えません。回答を変更した場合は自動で選ばれたポーズに戻ります。PNGには選んだ写真と版番号を反映します。

背景は薄い青灰色を基調に、4象限の淡い色と深い色の額装を組み合わせました。赤い車、本、ギターなどの小道具を毛色変更から除外する領域も追加しています。

## 2026-10-22 原画を引き継いだ毛色・模様の更新

猫の絵は前バージョンの5枚のPNGを引き継ぎます。図形の猫への描き直しは使用しません。

`cat-studio.js` は原画の画素を読み、毛の部分の色素を変えて表示します。輪郭・毛の細かな線・陰影・顔立ち・透明度を保ち、鼻・耳のピンク、目、植物、器を毛色変更から除外します。ブラウザ内で描画し、元PNGは上書きしません。

| 問い | 毛並みへの反映 |
| --- | --- |
| 1 | 白・黒・茶を基調にする |
| 2 | 単色・ぶち・三毛などの模様を決める |
| 3 | 顔・背中・体・尻尾など模様の配置を変える |
| 4 | 模様の面積と、元の5枚から選ぶポーズを変える |
| 5 | 瞳の色と模様の左右配置、カードの紋章を変える |

1問目と2問目から、白猫、黒猫、茶猫、白黒ぶち猫、三毛猫、白黒猫、さび猫、茶白猫、茶トラ猫に分かれます。後続の回答も模様の場所・広さ・左右差に反映します。同じ回答経路なら同じ毛並みになります。

元CSVの平均設計座標による猫の選定は維持し、4象限はカードの配色に使います。現在の243通りの回答経路では配色が月あかり14、花だより228、ひだまり1通りです。木もれびへの到達のために座標を書き換えることはしていません。毛色と模様の対応は作品独自の美術設計で、住民や実在の猫の性質を推定するものではありません。

選択肢のプレビュー、立体感のあるボタン、3秒の呼び出し演出、額縁・紋章・回答の足あとを加えたカード、PNG保存に対応。原画の猫が持つ時計用画像は内蔵の画像編集機能で制作し、制作条件を `dist/clock-image-prompt.json` に保存します。

`tests/cat-studio.test.cjs` は9種類の毛並み、配置・面積による模様の変化、243通りの回答処理、保留時、元画像の参照、輪郭・皮膚・透明度の保持を検証します。243通りすべてが異なる生物学的猫種という意味ではありません。

## 2026-10-22 先行更新

- 選択肢のプレビューで猫が反応し、確定後に小さな行動と研究の背景を表示。

- 猫の詳細から出典、URL、根拠要約、座標根拠、改善策、副作用、元CSVの全20項目にアクセス可能。

## 回答から家猫への対応

各選択肢は、場面に関連する元CSVの参照猫を設定し、その猫のX/Yを使用します。どの選択肢がどの猫を参照するかは作者の解釈です。参照猫と座標は回答後の研究欄で確認できます。保留を除く回答の平均座標を算出し、元CSVの座標とのユークリッド距離が最小の猫を表示します。同距離なら猫番号順。全回答を保留したときは中心座標 (5,5) を使います。回答ごとの座標は旅の記録で見られます。

座標は作品内の対応づけです。性格・健康・属性の推定や診断には使いません。

## ローカル表示・公開

静的サイトです。プロジェクトフォルダで `python3 -m http.server 8873 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8873/` を開きます。`file:` で開くとCSVを読み込めない場合があります。

GitHub Pagesは `main` への更新から `.github/workflows/pages.yml` で公開します。GitHubの Settings / Pages の公開元は GitHub Actions。

## GAS / Google Sheets / Discord

`config.js` の `gasUrl` が空の現在は、RPG、図鑑、研究表示、データ地図、端末内の足あと、カード保存が動きます。共有参加者やDiscord通知は未接続です。接続していないのに共有成功と表示することはありません。

接続する場合は以下を設定します。

1. 新しいGoogleスプレッドシートを作成。
2. Apps Scriptへ `gas/Code.gs` を登録。
3. Script Properties の `SPREADSHEET_ID` に記録用シートIDを設定。Discord通知は `DISCORD_WEBHOOK_URL` を同じプロパティに保管。
4. Webアプリを公開アクセスでデプロイし、そのURLを `config.js` の `gasUrl` に設定。
5. 更新をコミットして公開。

共有は本人が選びます。共有するのは任意のニックネーム、物語の地点、猫番号、回答イベント。GPS・住所は取得しません。共有中の地点は直近4分以内、記録の古い行は30日を超えると次の記録時に整理します。Discordには個人名を含まない冒険完了通知のみ送ります。WebhookはGitHubへ入れません。POSTの応答はブラウザーから確認できないため、送信とサーバーでの保存確認は同義ではありません。

端末内の進捗は `ieneko2-v3` に保存します。設問を改訂したため、旧版の回答は新しい設問へ自動転用しません。
