# 家猫クエスト II

地域への小さな関わり方を、5つの問いと100匹の家猫から探すシビックRPGです。

公開アプリ: https://tokmatsuno.github.io/ieneko2/

## 2026-10-22 更新

- 問いを地域参加・安心・時間・役割・共用空間の場面に再設計。
- 選択肢のプレビューで猫が反応し、確定後に小さな行動と研究の背景を表示。
- 回答の保留、前の問いへの移動、回答の変更、端末内の保存に対応。
- Kids版は問い・選択肢・反応・小さな行動をやさしい言葉にし、文字を拡大。読み上げにも対応。
- 元のメインビジュアルに加え、びっくり・ごはん待ち・好奇心・ひと休みの透明PNGを追加。
- 冒険のまちに端末内の足あとを表示。各地点を押して、問いと回答を振り返る。
- 元CSVのX/Yを使った100匹のデータ地図を追加。同座標の点だけ表示位置を少しずらし、値自体は変更しない。
- 猫の詳細から出典、URL、根拠要約、座標根拠、改善策、副作用、元CSVの全20項目にアクセス可能。
- 家猫カードのPNG保存。結果カードでは選んだポーズと色合いを反映。

## 研究とデータの扱い

元データ `dist/ieneko-100.csv` は [tokmatsuno/2026udc](https://github.com/tokmatsuno/2026udc) の100匹データを保持しています。このデータセットは創作類型と比較用の設計座標であり、住民の実測データ、心理尺度、医学的分類ではありません。

`evidence.js` に一次資料と照合した6件の書誌・要約・作品への反映・限界を収録。2026-10-22に以下を確認しています。

1. 山下真里佳・山本雄大・西堀泰英 (2024)「地域コミュニティ活性化と新たな担い手確保のプロセス：既往研究のレビューを基に」。DOI: [10.11361/cpijkansai.22.0_97](https://doi.org/10.11361/cpijkansai.22.0_97)
2. 佐伯亮太 (2024)「組織体制と構成員の選出方法から見る地域運営組織の担い手の現状について：兵庫県養父市の全自治協調査の結果から」。DOI: [10.11361/journalcpij.59.683](https://doi.org/10.11361/journalcpij.59.683)
3. Ryan & Deci (2000), Self-Determination Theory and the Facilitation of Intrinsic Motivation, Social Development, and Well-Being. DOI: [10.1037/0003-066X.55.1.68](https://doi.org/10.1037/0003-066X.55.1.68)
4. Granovetter (1973), The Strength of Weak Ties. DOI: [10.1086/225469](https://doi.org/10.1086/225469)
5. Ostrom (1990), Governing the Commons. DOI: [10.1017/CBO9780511807763](https://doi.org/10.1017/CBO9780511807763)
6. Sampson, Raudenbush & Earls (1997), Neighborhoods and Violent Crime: A Multilevel Study of Collective Efficacy. DOI: [10.1126/science.277.5328.918](https://doi.org/10.1126/science.277.5328.918)

元CSVで1と2の題名表記がリンク先と異なっていたため、表示時には正式書誌に補正しています。元CSVは書き換えず、原文も詳細の全項目表示に残します。各類型の個別根拠をすべて検証したわけではなく、未精査のものを含むことを画面で明示しています。

研究の知見を背景に問いを設計したもので、参照研究が本アプリや100類型の有効性を検証したわけではありません。地域参加が増える、継続するなどの効果は未検証です。

## 回答から家猫への対応

各選択肢は、場面に関連する元CSVの参照猫を設定し、その猫のX/Yを使用します。どの選択肢がどの猫を参照するかは作者の解釈です。参照猫と座標は回答後の研究欄で確認できます。保留を除く回答の平均座標を算出し、元CSVの座標とのユークリッド距離が最小の猫を表示します。同距離なら猫番号順。全回答を保留したときは中心座標 (5,5) を使います。回答ごとの座標は旅の記録で見られます。

座標は作品内の対応づけです。性格・健康・属性の推定や診断には使いません。

## UDC2026に向けた位置づけ

公式の大会名は「アーバンデータチャレンジ2026」です。[公式募集要領](https://urbandata-challenge.jp/udc2026_entry)の実用度・完成度・挑戦度を参考に、地域参加の入口を対話できる試作として設計しています。応募・受賞・公式認定や地域での実証を済ませたという意味ではありません。

この作品は設計データの可視化と研究の参照を行います。公的な統計から独自の猫100分類が実証されたと主張したり、表示上の架空のまちを実在する自治体の地理データと表現したりはしません。

## 画像

元の `dist/mike-main-visual.png` を維持。追加ポーズは内蔵 image_gen で同じ白黒猫を参照して制作しました。全4枚を `dist/cat-scared.png`、`dist/cat-hungry.png`、`dist/cat-curious.png`、`dist/cat-resting.png` に保存。制作プロンプト一式は `dist/image-prompts.json` に収録しています。100匹それぞれの固有イラストではなく、5種類のポーズと色合いを使い分けます。目や毛色を部位別に独立描き替えする仕組みではありません。

## ローカル表示・公開

静的サイトです。プロジェクトフォルダで `python3 -m http.server 8873 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8873/` を開きます。`file:` で開くとCSVを読み込めない場合があります。

GitHub Pagesは `main` への更新から `.github/workflows/pages.yml` で公開します。GitHubの Settings / Pages の公開元は GitHub Actions。

## GAS / Google Sheets / Discord

`config.js` の `gasUrl` が空の現在は、RPG、図鑑、研究表示、データ地図、端末内の足あと、カード保存が動きます。共有参加者やDiscord通知は未接続です。接続していないのに共有成功と表示することはありません。

接続する場合は以下を設定します。

1. 新しいGoogleスプレッドシートを作成。
2. Apps Scriptへ `gas/Code.gs` を登録。
3. Script Properties の `SPREADSHEET_ID` に記録用シートIDを設定。Discord通知は `DISCORD_WEBHOOK_URL` を同じプロパティに保管。
4. Webアプリを公開アクセスでデプロイし、そのURLを `config.js` の `gasUrl` に設定。
5. 更新をコミットして公開。

共有は本人が選びます。共有するのは任意のニックネーム、物語の地点、猫番号、回答イベント。GPS・住所は取得しません。共有中の地点は直近4分以内、記録の古い行は30日を超えると次の記録時に整理します。Discordには個人名を含まない冒険完了通知のみ送ります。WebhookはGitHubへ入れません。POSTの応答はブラウザーから確認できないため、送信とサーバーでの保存確認は同義ではありません。

端末内の進捗は `ieneko2-v3` に保存します。設問を改訂したため、旧版の回答は新しい設問へ自動転用しません。
