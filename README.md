# いえねこクエスト II

家猫の100匹データと既存のメインビジュアルを使い、問いに出会いながら5地点を歩くストーリーRPGです。回答によって能力値が育ち、100匹の家猫から相性の近い一匹が相棒になります。家猫カードはPNGで端末へ保存できます。

## いま動く機能

- 5つの地点で選択式の問いに回答
- Kids版のやさしい文章、文字拡大、音声読み上げ
- 回答に応じた猫の色味、向き、表情の雰囲気、ポーズの変化
- CSVの家猫100匹から結果に近い家猫を選択
- 家猫カードをPNGでダウンロード
- 5地点の物語マップと、参加者の地点を重ねる共有マップ
- ブラウザー内だけで動く初期状態

## GitHub Pages

リポジトリの Settings から Pages を開き、Build and deployment を GitHub Actions にします。`main` に push すると `.github/workflows/pages.yml` がルートのページを公開します。

## Google Apps Script と Google Sheets

GASは現在、共有マップの在席表示と匿名の冒険イベント記録を受け付ける実装です。GPSや住所は要求しません。共有マップへの参加は画面で本人が選びます。参加中は表示名、物語上の地点、家猫番号が4分以内の冒険者として表示されます。ログは30日より古い行を順次整理します。

1. Google Sheetsで新しいスプレッドシートを作成します。
2. Apps Scriptを開き、`gas/Code.gs` の内容を貼り付けます。
3. Apps Scriptのプロジェクト設定にスクリプトプロパティを追加します。`SPREADSHEET_ID` に作成したシートのIDを設定します。Discord通知を使う場合は `DISCORD_WEBHOOK_URL` も設定します。
4. デプロイからウェブアプリとしてデプロイします。アクセスできるユーザーを全員に設定します。匿名の公開アクセスになるため、子どもの本名や連絡先は表示名に使わないでください。
5. 発行されたウェブアプリURLを `config.js` の `gasUrl` に設定します。
6. `config.js` をコミットしてPagesを更新します。

Discordには冒険完了時に、個人名を含めない完了通知を送ります。Webhook URLは必ずApps Scriptのスクリプトプロパティに保管し、GitHubへ登録しません。

## 家猫100匹データ

`dist/ieneko-100.csv` は、公開リポジトリ [tokmatsuno/2026udc](https://github.com/tokmatsuno/2026udc) の家猫データソースをそのまま収録しています。名前、タイプ、領域、X/Y座標を使用します。元CSVの出典や根拠欄も保持しています。

## 表示の扱い

家猫の色味や向きは、選択結果から画面上で変化させます。現状は一枚のメインビジュアルに色調変化を適用する仕組みです。猫100匹それぞれの独立したイラスト生成、複数の描き分け済み目や表情、姿勢素材の切り替えはまだ含まれていません。

共有マップは現実のGPS地図ではなく、物語の5地点に参加者を表示します。GAS未設定でもRPG、図鑑、カード保存は遊べます。GASの公開デプロイ後に、共有マップとDiscord通知が有効になります。
