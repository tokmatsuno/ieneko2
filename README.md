# 家猫クエスト II

地域への小さな関わり方を、5つの問いと100匹の家猫から探すシビックRPGです。

公開アプリ: https://tokmatsuno.github.io/ieneko2/

## 現在のバージョン: ver2.08

フッターに「2026年度東京大学シビックテックデザイン学講座Team 1」と `ver2.08` を表示します。版番号は `version.js`、更新履歴は [CHANGELOG.md](CHANGELOG.md) に記録。以後のコミット件名も `verX.XX: 更新内容` とします。

ver2.08ではMAP2の共有集計・受付状態・保存確認を、認証情報を付けない通常のJSON通信で先に読み込みます。従来のJSONPを読み込めないブラウザ向けの変更です。通信が失敗した場合はJSONPへ切り替え、サーバーのエラーを成功として扱いません。保存の返答を読み返してから共有完了を表示する条件は維持します。

ver2.07では中間回答の毛色を、全身の灰色への混色から、白・黒・茶のぶち模様と境界が変わる表現へ修正しました。割合は回答の配分で、毛の画素面積を厳密に表す数値ではありません。最初の問いを保留した場合は後の回答から仮の毛色を作ります。まち・回答後のホーム・別ポーズの一覧でも回答の毛並みを引き継ぎます。

図鑑とMAP2の基準猫は、元の猫番号から9種類の表示用の毛並みを割り当てます。住民の回答や実在の猫の属性を生成したものではなく、元CSVの座標・出典は維持します。回答を集計した猫は集計の配分から描きます。縮小表示用の描画とキャッシュで、100匹の原寸画像を毎回加工する処理を避けます。

ver2.06では割合操作の折りたたみを廃止しました。各答えのカード内に0〜100%のスライダーと現在の割合を常時表示します。答えを押すと100%、つまみを動かすと残り2つを自動調整します。「AとBのあいだ」などの中間と「3つを同じくらい」も直接選べます。

## ver2.05: あいだの回答と家猫MAP2

- アプリ: https://tokmatsuno.github.io/ieneko2/?v=2.08
- 家猫MAP2: https://tokmatsuno.github.io/ieneko2/ienekomap2/?v=2.08

3つの選択肢をそのまま選ぶほか、各答えのスライダーで、A・B・Cの割合を0.1ポイント刻みで調整できます。ほかの2つを比例調整して合計100%を維持します。二択の中間へ移動するボタンも用意しました。端末内の保存は従来の選択肢番号も読み込めます。

座標は各問の参照猫3匹の座標を配分で加重平均し、保留を除く各問の座標を平均します。最も近い元データの猫を相棒にする規則は維持します。毛色・模様・位置・面積・瞳は配分に応じて原画の色素を加工します。ポーズは既存14種類から選ぶため、無限種類のポーズを生成する機能ではありません。カードと保存PNGのグラフは実際に選んだ5問のA・B・Cの割合で、能力・性格の得点ではありません。

家猫MAP2は7月保存版の象限・提案・可視化の考え方を引き継ぎ、次を用意しました。

1. 元CSV100匹を維持した参加の入口マップ。連続した座標や近い5匹を比較。
2. OpenStreetMapの実地図。回答者が任意に選んだ約1kmのセル中心に公開集計を表示。GPSは取得しません。
3. 地域・月・イベントでの絞り込みと、回答数・遊び／おやつ／環境の希望を表示。
4. またたび（遊びのツール）、ちゅーる（おやつ）、キャットタワー（環境）を近い基準猫の元CSVの提案から表示。参照猫・出典・副作用も確認でき、地域で試すためのメモを保存可能。
5. 同意した回答を共有先へ保存。個々の回答を非公開に保ち、地域・月・イベント・セル・設計ゾーンが同じ集計に5件以上ある場合だけ公開。端末や利用者の重複を本人確認する仕組みはなく、表示件数は人数ではありません。
6. CC BY 4.0の公開集計をCSV・GeoJSON・JSON APIで取得。公開ファイルの読み込みも可能。サンプル96件は架空で、実回答と別表示し、出力・再読み込み後もsample表記を維持。

細かな地理点・氏名・ニックネームは新収集の項目に含めません。市区町村名、イベントID、地域のセルは任意です。回答の送信は明示的な同意と操作がある場合のみ行い、POST後に保存確認APIで読み返せたときだけ完了を表示します。ネット不通時は端末内の記録を残し、再操作で同じ記録IDを用います。再識別リスクがゼロになるとの保証や、代表性のある住民調査との主張はしません。

収集データは自己選択サンプルです。提案は元データに基づく仮説で、希望の多さを効果とみなすものではありません。7月版の8軸レーダーにあった値を検証済みの心理尺度として再利用せず、今回は実回答の配分を可視化します。項目定義は [データ辞書](ienekomap2/data-dictionary.json)、収集サービスの管理方法は [gas/README.md](gas/README.md) を参照してください。既存Discordチャンネルへのリンクは維持しています。

元絵を参照した9種類のポーズを追加し、合計14種類にしました。毛を逆立てる猫、酔拳風、はいオッパッピー風、電動キックボード、昼寝、スポーツカー、ギター、読み聞かせ、庭づくりです。画像は `dist/cat-*.png`、内蔵画像編集機能へ渡した制作条件は `dist/pose-prompts-ver2.02.json` に保存しています。

猫の選定用の元座標は維持。中心 (5,5) を基準とする4象限に、まちでみんなと・まちで自分らしく・おうちでだれかと・おうちで気ままに、という創作の場面を割り当てます。象限の候補から5問の回答経路でポーズを決めます。根拠データからポーズや人物の性質を推定したという意味ではありません。

結果カードの「相棒の、ほかの一日を見る」から、同じ毛色・模様・瞳のまま別のポーズを選べます。この選択は記念写真だけに反映し、設計座標や選定された猫は変えません。回答を変更した場合は自動で選ばれたポーズに戻ります。PNGには選んだ写真と版番号を反映します。

背景は薄い青灰色を基調に、4象限の淡い色と深い色の額装を組み合わせました。赤い車、本、ギターなどの小道具を毛色変更から除外する領域も追加しています。

## 2026-10-22 原画を引き継いだ毛色・模様の更新

猫の絵は前バージョンの5枚のPNGを引き継ぎます。図形の猫への描き直しは使用しません。

`cat-studio.js` は原画の画素を読み、毛の部分の色素を変えて表示します。輪郭・毛の細かな線・陰影・顔立ち・透明度を保ち、鼻・耳のピンク、目、植物、器を毛色変更から除外します。ブラウザ内で描画し、元PNGは上書きしません。

| 問い | 毛並みへの反映 |
| --- | --- |
| 1 | 白・黒・茶を基調にする |
| 2 | 単色・ぶち・三毛などの模様を決める |
| 3 | 顔・背中・体・尻尾など模様の配置を変える |
| 4 | 模様の面積と、元の5枚から選ぶポーズを変える |
| 5 | 瞳の色と模様の左右配置、カードの紋章を変える |

1問目と2問目から、白猫、黒猫、茶猫、白黒ぶち猫、三毛猫、白黒猫、さび猫、茶白猫、茶トラ猫に分かれます。後続の回答も模様の場所・広さ・左右差に反映します。同じ回答経路なら同じ毛並みになります。

元CSVの平均設計座標による猫の選定は維持し、4象限はカードの配色に使います。3つの選択肢を単独で選ぶ243通りの回答経路では配色が月あかり14、花だより228、ひだまり1通りです。木もれびへの到達のために座標を書き換えることはしていません。毛色と模様の対応は作品独自の美術設計で、住民や実在の猫の性質を推定するものではありません。

選択肢のプレビュー、立体感のあるボタン、3秒の呼び出し演出、額縁・紋章・回答の足あとを加えたカード、PNG保存に対応。ver2.03の時計は、添付写真の光沢を参考にした独自の猫型振り子時計です。内蔵の画像生成・編集機能で制作し、制作条件を `dist/clock-image-prompts-ver2.03.json` に保存します。通常の猫は原画の毛並みを維持します。

`tests/cat-studio.test.cjs` は9種類の毛並み、配置・面積による模様の変化、243通りの回答処理、保留時、元画像の参照、輪郭・皮膚・透明度の保持を検証します。243通りすべてが異なる生物学的猫種という意味ではありません。

## 回答から家猫への対応

各選択肢は、場面に関連する元CSVの参照猫を設定し、その猫のX/Yを使用します。どの選択肢がどの猫を参照するかは作者の解釈です。参照猫と座標は回答後の研究欄で確認できます。保留を除く回答の平均座標を算出し、元CSVの座標とのユークリッド距離が最小の猫を表示します。同距離なら猫番号順。全回答を保留したときは中心座標 (5,5) を使います。回答ごとの座標は旅の記録で見られます。

座標は作品内の対応づけです。性格・健康・属性の推定や診断には使いません。

## GAS / Google Sheets / Discord通知

`config.js` の `gasUrl` が空の現在は、RPG、図鑑、研究表示、データ地図、端末内の足あと、カード保存が動きます。共有参加者やDiscord通知は未接続です。接続していないのに共有成功と表示することはありません。

接続する場合は以下を設定します。

1. 新しいGoogleスプレッドシートを作成。
2. Apps Scriptへ `gas/Code.gs` と `gas/IenekoMap2.gs` を登録（既存サービスの場合は gas/README.md を参照）。
3. Script Properties の `SPREADSHEET_ID` に記録用シートIDを設定。Discord通知は `DISCORD_WEBHOOK_URL` を同じプロパティに保管。
4. Webアプリを公開アクセスでデプロイし、そのURLを `config.js` の `gasUrl` に設定。
5. 更新をコミットして公開。

共有は本人が選びます。共有するのは任意のニックネーム、物語の地点、猫番号、回答イベント。GPS・住所は取得しません。共有中の地点は直近4分以内、記録の古い行は30日を超えると次の記録時に整理します。Discordには個人名を含まない冒険完了通知のみ送ります。WebhookはGitHubへ入れません。POSTの応答はブラウザーから確認できないため、送信とサーバーでの保存確認は同義ではありません。

端末内の進捗は `ieneko2-v3` に保存します。設問を改訂したため、旧版の回答は新しい設問へ自動転用しません。
