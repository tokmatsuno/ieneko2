# DJ IENEKO / ver2.20

公式アーティスト、所属事務所、レーベルのYouTube配信を確認した24曲を選びました。`playlist.json`に曲名、演奏者、動画ID、公式配信元、確認日を保持しています。歌詞・音源・ジャケットの複製や再配布はしません。

旧版のDJ画面と猫ごとの選曲を引き継ぎました。手元に残る旧CSV100匹は曲欄が未収録でした。別の旧版にあったStingのEnglishman In New York、TOTOのAfrica、Bon JoviのWanted Dead Or Aliveの3曲は保ち、新しい21曲を追加しました。

4象限に各6曲。象限・手動で選んだポーズ・本人がカードに選んだ好みから並べます。エディ風のギターにはPanama/Jump、かめはめ波風にはCHA-LA HEAD-CHA-LAなどを優先する、Team 1の作品内の対応です。嗜好・性格・気分の診断や、音楽の効果を測定した結果ではありません。

起動だけでは外部プレイヤーを読み込みません。視聴操作でYouTubeのプレイヤーを開きます。公式の視聴ページとSpotify検索にも移動できます。Spotify検索は、特定の録音・配信地域を保証するリンクではありません。ログイン、広告、再生可能地域、埋め込み可否は配信元の条件に従います。

「カードの話題に」を押した曲だけ、本人が選んだ一曲としてカードへ記載します。自動おすすめを本人の好みとして書き込みません。曲やカードの編集内容を、既存のGAS・公開猫CSVへ追加送信しません。
