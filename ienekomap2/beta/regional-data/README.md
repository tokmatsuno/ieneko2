# 全国比較で使う公開データ

## データの場所

- [全国1,741市区町村の統計CSV](municipalities.csv)：提供元から抽出した9項目。UTF-8 BOM付き。1行が1市区町村。
- [公開施設データ773行のCSV](places.csv)：福岡市88件、八王子市685件。取得した5つのCSVの範囲であり、全国や各市の全施設を網羅しない。同名・同所在地の重複1行をまとめ、画面では772件として表示する。
- [出典・年次・利用条件・取得日](sources.json)：CSVの項目コード、年次、出典、原典ファイルのSHA-256を収録。施設CSVの `source_id` は、このファイルの `place_sources[].id` に対応。
- 画面の「全国1,741市区町村の統計CSV」は、割合・分母・出典・利用条件も各行へ付けたCSVを出力する。
- 画面の「この地域の施設・イベントCSV」は、出典と利用条件を付けて出力する。追加CSVはこの端末内の表示にだけ使う。

## 全国共通の統計

出典：独立行政法人 統計センター [SSDSE-A-2026](https://www.nstac.go.jp/use/literacy/ssdse/)を加工して作成。
原典：[CSV](https://www.nstac.go.jp/files/SSDSE-A-2026.csv)、[項目定義・年次の解説](https://www.nstac.go.jp/files/kaisetsu-A-2026.pdf)。
版の公開日：2026年6月30日。取得日：2026年11月1日。
[提供元の利用条件](https://www.nstac.go.jp/info/site-policy/)はCC BY 4.0と互換性がある。

| CSV項目 | 原典コード | 年次・単位 |
| --- | --- | --- |
| population | A1101 | 2020年国勢調査・人 |
| under15 | A1301 | 2020年国勢調査・人 |
| working_age | A1302 | 2020年国勢調査・人 |
| over65 | A1303 | 2020年国勢調査・人 |
| households | A7101 | 2020年国勢調査・世帯 |
| general_households | A710101 | 2020年国勢調査・世帯 |
| single_households | A810105 | 2020年国勢調査・世帯 |
| libraries | G1401 | 2021年社会教育調査・施設 |
| community_centres | G1201 | 2021年社会教育調査・施設 |

`code` はe-Statの5桁地域コード。原典の冒頭のRを除く。2025年3月31日時点の1,741市区町村を収録。政令指定都市は市全体、東京都特別区は区単位で、町内会や町丁目の統計ではない。

年齢構成比の分母は `under15 + working_age + over65`。年齢不詳は除く。単独世帯割合の分母は `general_households`。分母0は欠測とし、0%へ置き換えない。施設1万人当たりの値は2021年の施設数を2020年の人口で割った参考値。

人口・世帯構成の比較は、年齢3区分割合と単独世帯割合の4項目の差の二乗平均平方根。人口規模の比較は人口比の対数差の絶対値。施設条件の比較は、図書館・公民館の人口1万人当たりの2項目の差の二乗平均平方根。単位が違う指標を合算しない。

## 施設データ

- [福岡市 公共施設一覧（福岡都市圏共通フォーマット）](https://data.bodik.jp/dataset/401307_ftoshiken_public_facility)：図書館12件、スポーツ52件、文化19件、美術館・博物館等5件。リソース更新日2025年1月7日。利用条件CC BY。
- [八王子市 公共施設一覧](https://www.city.hachioji.tokyo.jp/contents/open/002/p035934.html)：685件。公開ページ更新日2025年8月20日。CSVそのものの更新日を意味しない。利用条件CC BY 4.0。

分類は提供元のファイル区分、または施設名称からの分類とし、施設の全機能を推定しない。飲食情報が空欄なら記載なし。イベントや参加者募集を補作しない。利用時間・開催条件は施設の最新案内で確認する。

## 仮想回答と実施記録

既存の90件は `synthetic_beta` の仮想回答で、実際の地域差・活動実績・施策効果として使わない。
実施記録は `implementation_record`。検討中 `planned` と実施済み `completed` を分け、実施済みだけ参加延べ人数を入力できる。0人と未記録は区別する。記入者の申告であり、因果効果や地域全体の参加率は示さない。
実施記録は端末内保存とCSV交換。GASへは送信しない。既存の同意済み家猫回答をGAS・Googleスプレッドシートへ保存し、公開CSVを照合する経路は継続する。

## 更新方法

公式のCSVを再取得する場合は `scripts/fetch-region-sources.py` を実行し、原典・取得日・項目の年次を確認。その後 `node scripts/build-region-data.cjs` で画面用データを生成する。
`node scripts/build-region-data.cjs --check` と `node tests/region-data.test.cjs` で、同梱CSVとの一致・比較・欠測・出典・CSVの入出力を確認する。
